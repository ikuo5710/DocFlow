# 要求内容

## 概要

複数の画像ファイルを一括でOCR処理し、ファイル名の昇順でページを構成した単一のMarkdownファイルとして出力する機能を追加する。

## 背景

現在のDocFlowは1ファイルずつOCR処理する仕組みだが、スキャンした複数画像を一つのドキュメントとしてまとめたいユースケースがある。画像ファイル名の昇順でページ順を決定し、1つのMarkdownファイルにまとめることで効率的なドキュメント変換を実現する。

## 実装対象の機能

### 1. 複数画像の一括OCR処理（バックエンド）
- 複数の画像ファイルパスを受け取り、ファイル名昇順にソートしてOCR処理
- 各画像のOCR結果をページセパレータ(`\n\n---\n\n`)で結合
- 1つのOCRResultとして返却（pageCount = 画像数）

### 2. バッチOCRのUI
- ファイル一覧画面に「Batch OCR」ボタンを表示（画像ファイルが2つ以上ある場合）
- ボタン押下で全画像ファイルを一括OCR処理
- 処理結果をParallelViewerで表示（各画像がページとして表示）

## 受け入れ条件

### 一括OCR処理
- [ ] 複数画像ファイル（PNG, JPEG）を一括でOCR処理できる
- [ ] ファイル名の昇順でページ順が決まる
- [ ] 処理結果が1つのMarkdownとして結合される（ページ間は`---`区切り）
- [ ] 保存時は1つのmdファイルとして出力される

### UI
- [ ] 画像ファイルが2つ以上ロードされている時に「Batch OCR」ボタンが表示される
- [ ] 処理中はプログレス表示がある
- [ ] ParallelViewerで各画像をページとして閲覧・編集できる

## スコープ外

- PDFファイルのバッチ処理（PDFは既に複数ページ対応済み）
- 画像ファイルの並び順カスタマイズ（今回はファイル名昇順固定）
- バッチ処理の中断・再開機能
